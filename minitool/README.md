# HamilyMart 小红书小工具离线版

此目录是独立的小工具适配目标，源于网站提交 `557974ec4d62698c7a10752bf25407a4ca4d6a2f`。独立构建不会覆盖原网站源码、生产资源或 3MF 文件。之后修改网站功能时，需要同步这里的源码；它不是原站构建的自动镜像。

## 构建与检查

在 `hamilymart` 目录运行，使用现有 Node 依赖以及 Python 3 的 numpy、trimesh、fast_simplification、scipy、shapely、Pillow：

```sh
npx tsc -p minitool/tsconfig.json --noEmit
npx tsx --test minitool/tests/*.test.ts
node minitool/scripts/build.mjs
python3 -m unittest discover -s minitool/tests -p 'test_*.py'
node minitool/scripts/audit-package.mjs
```

构建只读取仓库内的 `public/models` 和 `public/thumbnails`。生成的 `dist/`、`generated/` 及 Python 缓存不提交到 Git。

按小红书规范交付前，需从创服平台上传页获取当前改写口令，安装对应的 `minitool-zip-builder` skill，再按实际安装路径运行其中的 `audit_artifact.py` 检查 `minitool/dist`。该 skill 是本机审计工具，不包含在本仓库。

将 `minitool/dist` 的内容压缩，确保 `index.html` 直接位于 ZIP 根目录，再用同一个 `audit_artifact.py` 检查 ZIP，并保留校验摘要。浏览器诊断另需可用的 Playwright 与 Chrome；通过 `HAMILY_PLAYWRIGHT` 可指定已有 Playwright 模块路径。

## 容器适配

- ES2017 / Chrome 61 目标的单个经典脚本；仅对实际使用的运行时 API 和 CSS 能力提供回退。
- XR 兼容层保留普通渲染所需的背景方法；回归测试直接调用 Three 的真实背景渲染路径，防止首帧异常被误判为设备不支持 3D。
- 52 组模型转为按需加载的本地经典脚本，不包含 GLB、网络请求、Base64 模型或动态模块。网格仅用于轻量预览；磁吸、配色、编号、定价等业务数据保留原逻辑。打印请继续使用原始模型。
- 网格转换按连通零件执行并逐件验证封闭性、孔洞拓扑、边界、面积和体积。薄片仅在证明属于凸拉伸体时精简轮廓；不再通过整体拉伸修正边界。无法满足质量门禁的零件保留更高精度几何。
- 70 张配色缩略图无损转为 WebP，构建时检查解码后的像素一致。
- 满足版本条件时优先使用小红书原生存储；不支持时回退浏览器存储。读取失败时保护原存档，写入结果有明确状态反馈。
- 容器禁止自动剪贴板访问，因此清单采用可选择文本供系统手动复制；粘贴导入、撤销、重做继续保留。
- 按产品要求始终使用真实 3D 模拟，不切换组件列表、静态图片或简视图。持续慢帧只调整渲染预算，不删除几何或停止 3D。缺少 WebGL2、模型加载或渲染失败时，保留设计并显示“重新加载3D”；失败的模型缓存会释放，重试可重新加载。
- 画布保留原生 MSAA，优先请求高性能 GPU（宿主是否采纳取决于设备）。单一控制器初始目标 60 FPS / DPR 1.5；连续健康窗口后提升到 DPR 2。连续慢窗口先降低像素密度，再降到 30 FPS / DPR 1.5，冷却后能自动恢复。没有 15 FPS / DPR 0.6 档位，也不再单凭三角形数量锁定低画质；目标帧率不代表设备保证值。
- 手势结束约 400ms 后恢复高清，剩余相机惯性继续以高清重绘，不再等待惯性完全归零。静止时停止 GPU 绘制；OrbitControls 未触发重绘的微小惯性位移不会累计到相机快照，避免恢复连接时出现漂移。交互画面限制 200 万像素、静止画面 300 万像素及 DPR 3；单边受 4096 和设备纹理上限约束，低 DPR 设备不强制超采样。初次 GPU 上传、缓冲区调整、后台恢复均排除在连续性能采样之外；无同步 GPU 回读。
- 模型转换阶段预计算 36° 硬边法线并按位置＋法线重新索引。运行时只创建类型化缓冲区，不重算法线；新格式版本防止旧缓存误用。当前 52 组模型保留 107,770 个三角形，渲染顶点从 323,310 降到 105,288，位置＋法线＋索引数据从 7,759,440 降到 3,173,532 字节。代价是包内文本法线数据增大；总包体仍受 10 MiB 门禁限制。
- 编辑时按组件差异更新，位置修改复用对象，配色/孔盖等修改只替换受影响组件。拖动期间缓存磁吸候选，每个指针事件只构建一次射线。重复几何与完全相同材质的组件用实例批共享绘制；保留原对象身份、拾取、磁吸表面与爆炸变换。透明和自定义着色器材质不参与合批。
- 从上方转向底部时，垫料逐渐过渡至 20% 不透明度，回到上方恢复完全不透明；渐变完成后仍停止额外绘制。尺寸开关为 3D 区域左上角的独立图标按钮。
- 阴影在组件、灯光、爆炸变换或可见性变化时更新，普通旋转视角复用阴影贴图。正常状态不再每帧遍历场景统计复杂度或隐藏垫料碎屑。
- WebGL context lost 暂停绘制，context restored 后自动续绘；只有真实 3D 成功绘制后才关闭错误提示。手动重试及自动恢复保留设计和相机快照；不会自动循环重试。
- 无腿始终可以选择，包括已有泳池的设计。有垫料时平台底面位于垫料高度；没有垫料时位于原始地面。修改垫料、增加泳池及恢复编号均保留明确选择的无腿状态；已有正腿配置的调整规则不变。
- CSS 包含旧内核布局、安全区、视口高度、横向列表和软键盘的局部回退。
- 顶栏用 `--minitool-native-left-space` / `--minitool-native-right-space` 为容器返回按钮及右侧两个按钮预留空间。价格位于 3D 区域右上，选中组件的操作栏避开价格行。
- 视角由用户的旋转、平移和缩放手势控制。选中、配色、增删组件、移除平台、腿高、垫料、撤销/重做及拆解/恢复均保留当前相机位置、朝向和缩放；画布尺寸变化仅更新投影。初次打开、确认清空、成功导入设计或成功新增平台会重新取景；新增平台会将当前全部平台纳入画面。悬浮操作栏自行调整位置，不再移动相机；选择变化复用现有模型网格。

## 验证边界

自动测试与静态审计通过不代表容器已验收。Chrome 61 / Android 8.1 的 CSS 兼容性及设备性能均未实测；首屏耗时、帧率、内存和实际降档情况待记录。

请将最终同一个 ZIP 上传创服平台，先完成平台模拟器的完整功能验证，再分别在 Android 和 iOS 真机扫码验证。重点检查存档恢复、手动复制/粘贴导入、触控旋转和吸附、爆炸图、横竖屏安全区、软键盘、低性能降档及后台恢复。本次未登录、上传或发布。

`scripts/diagnose-render.cjs` 可使用已有 Playwright 和 Chrome 对本地离线包做受限 CSP 下的渲染故障诊断，记录资源加载、绘制调用、异常和截图；它不是容器验收，也不能代表 Android / iOS 真机表现。

`scripts/benchmark-orbit.cjs <label>` 将当前构建复制到临时快照，使用相同手机尺寸及轨迹进行三轮连续旋转对照，记录真实 WebGL 提交帧间隔、每帧绘制次数及分辨率。`HAMILY_BENCH_PLATFORMS=3` 可运行三平台对照，并分别统计主画面与阴影绘制次数。报告包含浏览器/GPU 环境与构建哈希；提交帧率并非 GPU 完成时间或真机屏幕帧率。

`scripts/diagnose-camera.cjs <label>` 在真实浏览器内比较编辑前后提交给 WebGL 的视图和投影矩阵，同时检查操作过程中的瞬间变化，验证普通编辑保留视角、清空/导入允许重置、新增平台必须重新取景。默认检查小工具构建；通过 `HAMILY_CAMERA_DIST` 或 `HAMILY_CAMERA_URL` 可检查网站版，通过 `HAMILY_CAMERA_OUTPUT` 可指定报告目录，`HAMILY_REDUCED_MOTION=1` 可验证减少动态效果时的同步拆解。诊断仅在测试浏览器中注入，不进入交付包，也不读取 GPU 数据。

`scripts/diagnose-recovery.cjs <label>` 对本地构建注入一次资源请求失败、WebGL 连接丢失、启动能力暂不可用及虚拟慢帧，验证重试/恢复保留设计与视角、复杂场景始终维持 3D。`HAMILY_RECOVERY_DIST` 可指定网站构建。故障注入只在测试浏览器中生效；虚拟慢帧不是实际设备性能测量。

## 2026-10-12 优化验证

单元及几何测试覆盖可恢复画质、高清尾帧、相机保留、异步组件替换、磁吸候选失效和合批后的拾取/爆炸变换。生成器会逐网格比对重索引前后的 Float32 三角形位置和法线流；打印源文件没有改动。

本地 Chrome 诊断记录实际 drawing buffer、MSAA、首个高清尾帧和最终静止帧，两者分别计时，避免将惯性结束时间误当高清恢复时间。所有本地性能报告仅代表该机器与浏览器的提交行为，不代表小红书或手机屏幕呈现帧率。最终同机对照需依次使用网页版 Chrome、小工具包 Chrome、同一小工具包小红书，并保持相同设计、视角和尺寸。
