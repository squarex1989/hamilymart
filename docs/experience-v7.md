# 目录 7：移动端搭建与居住预览

## 独立手机与桌面工作台

手机 `MobileWorkbench.tsx` 与桌面 `DesktopWorkbench.tsx` 分别渲染，只共享装配状态和业务动作。手机横滑单排组件卡片，分类固定底部；商品名下显示价格，横滑区左右始终保留 16 px 留白。选中或添加组件后部位可以横滑，颜色在可用宽度内换行，不再需要横滑选色；只保留一个返回标题栏。平台编辑还提供腿高与缺失小圆盖的放回操作。桌面采用网格商品侧栏，支持指针拖动。两端都直接点选画面中的已装组件，没有“已搭建”总览入口。

手机使用 50 px 网站页头，底部控制区常规竖屏保留约 272–332 px，短屏约 248 px，按实际 `dvh` 适应外部浏览器标题栏；3D 模型填满剩余区域。页头右侧的价格打开搭配清单，清单顶部固定“复制搭配编号”和关闭按钮，只有下方清单独立滚动；复制包含 SKU、数量、配色、部件编号、合计和搭配编号，不下载文件。页头价格左侧提供“导入搭配”，支持粘贴完整清单或单独编号，严格校验后直接替换当前设计，无二次确认，整次导入可以撤销。3D 画面底部的横条集中显示“增加平台”“换个配色”“垫料高度”“显示尺寸”及清空按钮，没有全局菜单。尺寸开关展示实际模型整体长、宽、高，单位 cm，排除垫料与辅助框。清空前显示确认弹窗，确认后恢复默认的一块平台及初始配色、脚长和垫料；取消不改变设计，清空仍可后退恢复或前进重做。

选中组件显示黄色半透明虚线包围框：线宽 2.5 px、线透明度 0.5、面透明度 0.2。物品名称显示在框上方的工具栏顶部，适用的旋转、移除操作紧随其下。合法安装位置以小圆圈显示，位置仍经过真实磁吸和碰撞校验；小圆圈可直接用于重新安装。底部编辑区不再重复旋转、移除或还原配色。小圆盖只有在所属平台正在编辑时显示辅助描边并能单独选择。

添加商品会立即自动安装并进入编辑，没有自动布局成功提示或常驻操作引导。无法放置时仍显示“放不下去了”；迁移、保存失败等必要反馈保留。所有修改即时生效并自动保存，没有保存按钮；返回仅退出编辑。组件列表标题栏提供后退、前进，最多保留 20 步历史，新操作会清空重做分支。

轨道镜头支持完整俯仰，可转到下方查看底部。底视时暂时隐藏垫料、地面阴影和网格，补光显示底部结构；转回上方后恢复。场景背景保持浅灰色。镜头按底部工具栏的实际高度上移投影中心，为按钮预留空间；窗口变化、恢复视角和拆分展示都使用可视区域。

## 部位颜色与整体风格

当前可选 13 色，按选择器顺序为杏色、绿色、红色、黄色、粉色、蓝色、白色、琉璃绿、桃木、仿木、深棕、黑色、灰色。黄色统一为明亮暖黄 `#F3B34E`，放在原黄色第 4 位，默认黄色也同步更新。`butter` 保持索引 3，历史 `yellow` 保持索引 14 作为同色兼容别名，但不重复显示色块。黑色为 `#303331`，灰色为 `#A4ABA9`。桃木、仿木、深棕全部使用纯色，不显示木纹或凹凸纹理，琉璃绿使用光滑清漆表面。`COLORS` 的旧索引不重排；大理石、旧鼠尾草/香芋紫仅保留旧编号兼容，不在 `AVAILABLE_COLORS` 中显示。

礼物盒丝带、五角星继续独立配色；波浪楼梯的踏面 `G05` 与杏色底座 `G05-base` 分开。三边草丛 G15/G16/G17 共用一个控制，双支柱 W01/W02 跟随二层平台 A02。旧从件颜色仍保留在存档，画面与订单都按新的联动关系读取主件颜色。帽子小屋提供 `G03-window` 窗框和 `G03-trim` 帽檐与圆球两个细节槽，默认均为杏色。手动配色、整体风格及旧存档显示通过 `resolveHatContrast` 保持细节对比：细节与帽子主体相同，或两者同在杏色/白色浅色组时，细节会改用对比色；主体为杏色、白色或仿木时回退绿色，其他主体回退杏色。网页拆分窗框不改变源几何或生产 3MF。

“换个配色”依次循环以下五种风格：

| 风格 | 配色 |
| --- | --- |
| 圣诞礼物 | 杏色、绿色、红色，默认黄色更新为暖黄；L 型与方糖屋顶盖为杏色 |
| 暖木小筑 | 仿木、深棕、桃木均为纯色；L 型与方糖屋顶盖为桃木 |
| 草莓奶油 | 奶油杏、柔粉、草莓红、白色、暖黄；L 型与方糖屋顶盖为杏色 |
| 晴空棉云 | 仅云朵白、浅蓝、奶油杏、暖黄与灰，不含深绿；L 型与方糖屋顶盖为白色 |
| 琉璃花园 | 白色、琉璃绿、柔粉、暖黄；L 型与方糖屋顶盖为粉色 |

风格始终映射原始默认材质角色，覆盖全部平台、孔盖、池盆、腿和组件独立颜色槽，不基于上一次风格继续替换。五种风格都让每个平台的 P01 与 H01–H06 同色、A02 与 G05-base 同色；手动配色时这些槽仍独立，不会因修改平台颜色而强制改掉楼梯底座或圆盖。切换不改变组件几何、数量、位置、垫料或保留的仓鼠字段；可撤销，也会进入本地保存与搭配编号。切换后仅短暂提示风格名称，按钮不常驻显示风格名称或“自定义”。

`getProductStyleColors(productId,index)` 和 `getBaseStyleColors(index)` 提供预览、商品新增和整体切换共用的完整配色。晴空的帽身为浅蓝、窗框为暖黄、帽檐与圆球为白，明确保持对比，避免自动回退引入深绿。原有手动配色与旧编号的帽子对比规则保持不变。

圣诞礼物内部 ID 保持 `original`。五种官方配色统一 L 型与方糖小屋的顶盖：依次为杏色、桃木、杏色、白色、粉色，圣诞礼物的两种屋顶也默认杏色。杏色按用户参考图取色为 `#FEF1DB`，实时模型与缩略图同步；三种木色的 RGB、存档 ID 不变，只移除木纹。切换到木色时会清除复用材质的贴图和旧程序纹理，旧大理石兼容显示及琉璃绿清漆效果仍保留。

旧 `yellow` 配色在手机和桌面都选中同一个黄色色块；帽子主体和细节分别使用 `butter`、`yellow` 时也会按同色处理。主题识别将二者视为相同，四款主题现有材料 ID 继续保留。旧存档中的原 ID 不改写，画面和清单统一显示为黄色。

## 真实磁吸与三平台

P01 本体的 32 个钢片接收位与用户提供的打印板截图一致。源孔心是 10/90/110/190/210/290 mm；平台本体不含大圆孔中心的四点。H06 大盖独立提供 (90,90)、(90,110)、(110,90)、(110,110) 四点，移除它安装泳池时四点消失。`P01_TOP_XY` 与 `H06_TOP_XY` 分别维护；画面的小圆圈表示当前组件的合法安装位置，不替代完整孔位数据。匹配的是接触面，不是钢片实体中心。

最多三块平台，只向右侧连续增加，原点分别为 (0,0)、(300,0)、(600,0)。三块始终同高、完整贴边；删除中间平台后，右侧平台及其全部后代向左平移。各平台配色、孔盖、泳池独立。

单磁铁花圃和食盆可安装在一层任意几何可行的接收位，也可使用兼容的房屋顶面。单磁件以真实接收点作为支撑锚点，允许外形伸出平台边缘或部分覆盖圆洞，仍拒绝与已有实体相撞；没有接收点的位置不能安装。二层原有草栏的保守安全区域和朝向限制保留。其他磁吸商品仍要求至少两点匹配。

V12 新增 SS01 跷跷板（180×80 mm，金黄色），正中心底部单磁孔接触点为源坐标 (90,90,110)。它作为 `seesaw` 追加在商品目录末尾，不改变旧编号中的商品索引；允许使用一层任意真实单磁位，碰撞范围预留约 ±12° 摆动空间。V16 的 3MF、网页及商品图都按 10° 倾斜姿态展示；固定底座及中心磁位不变，两端高差约 3 cm。

组件选择器只显示四款不同管道：直管道、弯管道、侧开口直管道、顶开口弯管道。新弯管道 `pipe-lt2n` 使用正式源 LT2NT 加 LT2B，旧 ST3/LT1/LT3 商品 ID、模型和编码位置全部保留，导入后仍能选中、换色与移除，但不在可购买组件列表中重复显示。全部管道连同底座统一 ¥8，隐藏的历史款价格相同；L 型转角屋 ¥35，泳池 ¥25。平台和其他商品维持目录当前价格。

正式模型为 Steel V16，沿用 V15 的二层平台调整：A02 二层板精确为 300 mm 宽，与底层平台齐边。帽屋整体向 +X 移动 5 mm、左右草栏内移 5 mm，后草栏收短并保留七个完整波峰；花圃与食盆的共用接收点向 −X 移到 `(280.5,264,200)`。含帽屋、草栏、支柱的套餐不越过 300 mm 边界，三个礼物盒可以同向并排，实体接缝无相交。网站仍按真实孔位与实体碰撞验证，不会为了旋转自动移动旁边商品。

G05 沿用 V14 上端 L 形扣搭，搭板顶面 Z=200 mm，与 A02 盲槽配合；上端不再使用磁铁或钢片，只保留底部一个磁铁。完整源套装有 49 片钢片、39 枚磁铁，其中 A02 五片钢片用于帽屋四点和花圃/食盆共用点。楼梯、双支柱、房体和地面磁位保持 V14 位置。相对 V14，实际重打仅 A02 与 G15 后草栏；其余五个联动零件只是改变装配位置，可继续使用原实体。更早版本需要同时配套 V14 扣搭楼梯。

碰撞检测按楼梯实际几何分成连续高度段，保留踏面上方的空隙；旋转按 90° 步进，携带全部后代，在同一父平台内寻找合法磁位。三平台共享相同安装规则。

## 垫料和支撑脚

`bedding` 为 `{mode:'none',depth:0}`、`{mode:'thin',depth:50}` 或 `{mode:'thick',depth:100|200|300}`，单位毫米。选择 0 cm 不生成垫料；薄铺 5 cm，厚铺提供 10/20/30 cm。HM3 保留模式 0/1，追加模式 2 表示不铺，只接受 `[2,0]`。垫料高度与 0/10/20/30 cm 腿长分开保存，例如 30 cm 腿可以配 20 cm 厚铺。设置更深的垫料时，如果已有腿为非零且短于新深度，`setBedding` 会将腿升高到该深度；更长的腿保持，不给无腿平台自动添加支撑脚。减薄垫料不会缩短腿，手动修改腿长也不改垫料；旧编号导入不会自动改写原有脚长。无腿时把平台底部放在垫料顶面，仍不能安装向下嵌入的泳池。

源装配面坐标维持 z110，不因脚长而变；渲染的 `getDisplayElevation` 为有腿时 `legHeight-100`、无腿时 `bedding.depth-100`。平台表面与垫料的高差按各自参数真实展示。垫料采用一个连续的圆角体积，沿整组平台的外沿四周各扩出 50 mm，不在相邻平台之间重复加边；表面轻微起伏，顶部和侧面有实例化卷曲木屑。池盆仅在与垫料相交的高度范围预留空腔，留洞能看到下面的垫料。

30 cm 腿的网页零件 ID 为 Y01–Y04，价格独立定义为 `extraTallLegSurcharge`。`scripts/prepare-tall-legs.py` 从源 X01–X04 的 20 cm 网格延长中段，保留两端轮廓与顶部磁座；输出保持水密、总长 300 mm。新增腿是网页预览派生件，未写入现有生产 3MF。

## 仓鼠模拟

当前暂不开放，等待用户提供更精细的模型。`data/features.ts` 的 `hamsterPreview` 默认关闭，同时隐藏入口、面板和相关引导，不创建场景中的仓鼠模拟。已有存档与搭配编号的仓鼠字段保留以兼容以后恢复。

`data/hamsters.ts` 定义品种与花色，`state.hamster` 保存选中的 ID 或 null。提供金丝熊、三线、一线、公婆、中国仓鼠及相应花色。尺寸用于视觉和通路净空判断，不用于个体测量或繁育判断。

程序化 3D 仓鼠包含步行、嗅探、站立张望及可通行洞口的钻入动作。移动路径以真实模型表面及碰撞为约束，楼梯连接楼层，布局改变后重建可行区域。泳池按空盆展示，不表现游泳。仓鼠和垫料属于场景预览，不计入商品清单或价格。

品种参考：[Merck Veterinary Manual](https://www.merckvetmanual.com/multimedia/table/hamster-breeds-commonly-kept-as-pets)。探索、挖掘等动作参考：[RSPCA 仓鼠行为](https://www.rspca.org.uk/adviceandwelfare/pets/rodents/hamsters/behaviour)。垫料厚度选项是本工具的视觉参数，不是饲养建议。

## 保存与验证

无本地存档时调用 `createNewUserState()`，以真实磁吸和碰撞规则生成 0 cm 垫料、10 cm 腿平台、泳池、礼物盒、二层帽子和袜子花圃，总价 ¥180，配色为圣诞礼物。有存档时恢复原设计，不覆盖用户配置；清空仍独立使用基础平台默认状态。

新编号仍为 HM3，目录版本 7，完整保存三平台、颜色、腿长、垫料、仓鼠和配件。黄色统一仅改变显示 RGB 与选择器入口，保留两个历史 ID 及原序号；调整价格不改变搭配编号，订单按当前目录计算。本地自动保存当前配置，撤销/重做历史仅在当前页面会话内保留。资源缓存版本单独更新为 `steel-v16-apricot-starter1`，不改变 HM3 格式或商品、颜色的旧索引。

旧目录 6 的 HM3 和本地存档先按冻结的旧几何严格校验，再迁移到 300 mm 二层平台。旧版非法的重叠或磁位不能借升级绕过验证。帽屋保留存储位置与虚拟 pivot，由 +5 mm 的新源装配坐标自动对齐；二层花圃/食盆按其父件朝向内移 5 mm，一层和 L 型屋顶上的单磁件保持原位置。ID、自定义颜色、全部组件、平台、腿高和垫料值保留；迁移后再做一次新目录验证，失败时保留原存档且不删组件。

旧 HM1/HM2 继续经过各自历史版本迁移，包括补齐草栏/支柱颜色、将前/后/左第二平台连同子件迁到右侧，以及为旧一层帽屋寻找兼容二层位置。找不到合法位置就提示并保留原件。新增颜色槽只追加，历史丝带、星星和实体颜色位置不变。当前目录 7 则只做严格校验，不进行放置修复。

运行 `npm test` 和 `npm run build` 验证当前工作树。回归覆盖历史编码、严格目录 6 迁移、四朝向子件内移、三套同向贴边、实际 GLB 尺寸和扣搭、联动及独立配色、五种风格同色规则、窗框拆色、管道去重、价格、垫料和尺寸测量。最终通过数量以当次运行输出为准。

维护入口：`catalog.ts` 管商品、独立配色及联动；`assembly.ts` 管几何、状态和清单；`config-code.ts` 管迁移与编码；`color-styles.ts` 管五种整体风格。`App.tsx` 负责共享状态、20 步历史和画面入口；`MobileWorkbench.tsx` 与 `DesktopWorkbench.tsx` 分别实现手机、桌面工作台。`AssemblyScene.tsx` 组合场景，`scene-annotations.ts` 管选择框与尺寸，`bedding-scene.ts`、`hamster-scene.ts`、`scene-finishes.ts` 分别管理垫料、隐藏的仓鼠预览与材质。

帽子小屋可直接自动安装在一层：保留源 146×94 mm 孔距，用两孔对的中点对齐一层 100 mm 间距的实际钢片，每枚磁铁最大偏心 3 mm。候选仍要求两个不同钢片、同一接触平面、不与物件及泳池干涉，并能在三个平台上四向安装。偏心匹配仅适用于当前帽屋的一层安装，二层及其他配件维持原规则；冻结旧目录 2–6 的校验不放宽。

## 爆炸视图

双击画布空白处（手机双点）往返切换爆炸视图，原生鼠标双击与触摸配对事件去重，点击模型本身、拖拽或多指操作不会触发。按组装关系展开：一层平台、所有圆盖与桌腿保持一体；帽屋所有颜色体、楼梯踏面与底座、礼物盒与丝带星星、管道与支撑各自保持整体；三片草栏一起移动，二层平台与白柱保持一体。其他部件保持原有水平位置与上下顺序，L 型与方糖小屋顶盖始终在对应屋体上方。基于实际几何包围盒留垂直间距，不改变网格与朝向；镜头适配窄屏并扩展远裁剪面。

展开/收拢约 550 ms，系统要求减少动态效果时立即切换。展开时仍能旋转和缩放，不显示磁吸标记、选择框或尺寸，不允许拖动拆开的组件；任何设计编辑会先恢复组装。恢复精确还原模型变换与原相机。展示状态仅保存在内存，不写搭配编号、价格、存档或撤销历史。仅展开后显示“恢复组装”按钮；未展开时不显示入口、操作提示或摇动权限请求。
