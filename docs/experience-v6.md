# 目录 6：移动端搭建与居住预览

## 独立手机与桌面工作台

手机 `MobileWorkbench.tsx` 与桌面 `DesktopWorkbench.tsx` 分别渲染，只共享装配状态和业务动作。手机横滑单排组件卡片，分类固定底部；商品名下显示价格，横滑区左右始终保留 16 px 留白。选中或添加组件后部位可以横滑，颜色在可用宽度内换行，不再需要横滑选色；只保留一个返回标题栏。平台编辑还提供腿高与缺失小圆盖的放回操作。桌面采用网格商品侧栏，支持指针拖动。两端都直接点选画面中的已装组件，没有“已搭建”总览入口。

手机使用 50 px 网站页头，底部控制区常规竖屏保留约 272–332 px，短屏约 248 px，按实际 `dvh` 适应外部浏览器标题栏；3D 模型填满剩余区域。页头右侧的价格打开搭配清单，清单内提供导出与分享/导入搭配编号。3D 画面底部的横条集中显示“增加平台”“切换风格”“垫料高度”“显示尺寸”及清空按钮，没有全局菜单。尺寸开关展示实际模型整体长、宽、高，单位 cm，排除垫料与辅助框。清空前显示确认弹窗，确认后恢复默认的一块平台及初始配色、脚长和垫料；取消不改变设计，清空仍可后退恢复或前进重做。

选中组件显示黄色半透明虚线包围框：线宽 2.5 px、线透明度 0.5、面透明度 0.2。物品名称显示在框上方的工具栏顶部，适用的旋转、移除操作紧随其下。合法安装位置以小圆圈显示，位置仍经过真实磁吸和碰撞校验；小圆圈可直接用于重新安装。底部编辑区不再重复旋转、移除或还原配色。小圆盖只有在所属平台正在编辑时显示辅助描边并能单独选择。

添加商品会立即自动安装并进入编辑，没有自动布局成功提示或常驻操作引导。无法放置时仍显示“放不下去了”；迁移、保存失败等必要反馈保留。所有修改即时生效并自动保存，没有保存按钮；返回仅退出编辑。组件列表标题栏提供后退、前进，最多保留 20 步历史，新操作会清空重做分支。

轨道镜头支持完整俯仰，可转到下方查看底部。底视时暂时隐藏垫料、地面阴影和网格，补光显示底部结构；转回上方后恢复。场景背景保持浅灰色。

## 部位颜色与整体风格

当前可选 11 色：杏色、绿色、黄色、红色、白色、蓝色、琉璃绿、粉色、桃木、仿木、深棕。源四色 RGB 不变；桃木和仿木使用纯色，深棕保留方向性木纹，琉璃绿使用光滑清漆表面。`COLORS` 的旧索引不重排；大理石、旧鼠尾草/香芋紫仅保留旧编号兼容，不在 `AVAILABLE_COLORS` 中显示。

礼物盒丝带、五角星继续独立配色；波浪楼梯的踏面 `G05` 与杏色底座 `G05-base` 分开。三边草丛 G15/G16/G17 共用一个控制，双支柱 W01/W02 跟随二层平台 A02。旧从件颜色仍保留在存档，画面与订单都按新的联动关系读取主件颜色。帽子小屋提供 `G03-window` 窗框和 `G03-trim` 帽檐与圆球两个细节槽，默认均为杏色。手动配色、整体风格及旧存档显示通过 `resolveHatContrast` 保持细节对比：细节与帽子主体相同，或两者同在杏色/白色浅色组时，细节会改用对比色；主体为杏色、白色或仿木时回退绿色，其他主体回退杏色。网页拆分窗框不改变源几何或生产 3MF。

“切换风格”依次循环以下五种风格：

| 风格 | 配色 |
| --- | --- |
| 原色圣诞 | 原模型杏色、绿色、红色、黄色 |
| 暖木小筑 | 仿木、深棕、桃木 |
| 草莓奶油 | 奶油杏、柔粉、白色、暖黄 |
| 晴空棉云 | 云朵白、浅蓝、奶油杏、暖黄 |
| 琉璃花园 | 白色、琉璃绿、柔粉、暖黄 |

风格始终映射原始默认材质角色，覆盖全部平台、孔盖、池盆、腿和组件独立颜色槽，不基于上一次风格继续替换。切换不改变组件几何、数量、位置、垫料或保留的仓鼠字段；可撤销，也会进入本地保存与搭配编号。切换后仅短暂提示风格名称，按钮不常驻显示风格名称或“自定义”。

## 真实磁吸与三平台

P01 本体的 32 个钢片接收位与用户提供的打印板截图一致。源孔心是 10/90/110/190/210/290 mm；平台本体不含大圆孔中心的四点。H06 大盖独立提供 (90,90)、(90,110)、(110,90)、(110,110) 四点，移除它安装泳池时四点消失。`P01_TOP_XY` 与 `H06_TOP_XY` 分别维护；画面的小圆圈表示当前组件的合法安装位置，不替代完整孔位数据。匹配的是接触面，不是钢片实体中心。

最多三块平台，只向右侧连续增加，原点分别为 (0,0)、(300,0)、(600,0)。三块始终同高、完整贴边；删除中间平台后，右侧平台及其全部后代向左平移。各平台配色、孔盖、泳池独立。

单磁铁花圃和食盆可安装在一层任意几何可行的接收位，也可使用兼容的房屋顶面。单磁件以真实接收点作为支撑锚点，允许外形伸出平台边缘或部分覆盖圆洞，仍拒绝与已有实体相撞；没有接收点的位置不能安装。二层原有草栏的保守安全区域和朝向限制保留。其他磁吸商品仍要求至少两点匹配。

V12 新增 SS01 跷跷板（180×80 mm，金黄色），正中心底部单磁孔接触点为源坐标 (90,90,110)。它作为 `seesaw` 追加在商品目录末尾，不改变旧编号中的商品索引；允许使用一层任意真实单磁位，碰撞范围预留约 ±12° 摆动空间。网页按源中立姿态展示。

组件选择器只显示四款不同管道：直管道、弯管道、侧开口直管道、顶开口弯管道。新弯管道 `pipe-lt2n` 使用正式源 LT2NT 加 LT2B，旧 ST3/LT1/LT3 商品 ID、模型和编码位置全部保留，导入后仍能选中、换色与移除，但不在可购买组件列表中重复显示。

V13 将 G05 搭板顶面改为 Z200 平面，磁座下沉；同步使用 V13 A02 承接槽。两组必须一起更新，商品坐标、外包围盒及原杏红配色保持不变。碰撞检测把楼梯按实际源几何分为连续高度段，避免将低处踏面上方的空气当成实体；相邻小屋可使用真实留空区域，实际二层平台和围栏相撞仍会拒绝。三平台使用相同局部安装规则，旋转时携带全部后代并遍历同父平台的全部候选。A02 二层板实际宽 310 mm，底层平台为 300 mm；并排同向的二层板可能真实相交，不能因用户继续旋转而忽略碰撞。已复现两侧 0°、中间 90° 的三组小屋布局：中间的 0° 候选与相邻二层板相交，即使移除帽屋也仍受阻。分别旋转两侧至 90° 可形成合法的三组同向布局。拒绝此类方向时返回包含两种真实宽度的明确原因，不自动移动旁边组件。

## 垫料和支撑脚

`bedding` 为 `{mode:'thin',depth:50}` 或 `{mode:'thick',depth:100|200|300}`，单位毫米。薄铺默认 5 cm；厚铺提供 10/20/30 cm。垫料高度与 0/10/20/30 cm 腿长分开保存，例如 30 cm 腿可以配 20 cm 厚铺。设置更深的垫料时，如果已有腿为非零且短于新深度，`setBedding` 会将腿升高到该深度；更长的腿保持，不给无腿平台自动添加支撑脚。减薄垫料不会缩短腿，手动修改腿长也不改垫料；旧编号导入不会自动改写原有脚长。无腿时把平台底部放在垫料顶面，仍不能安装向下嵌入的泳池。

源装配面坐标维持 z110，不因脚长而变；渲染的 `getDisplayElevation` 为有腿时 `legHeight-100`、无腿时 `bedding.depth-100`。平台表面与垫料的高差按各自参数真实展示。垫料采用一个连续的圆角体积，沿整组平台的外沿四周各扩出 50 mm，不在相邻平台之间重复加边；表面轻微起伏，顶部和侧面有实例化卷曲木屑。池盆仅在与垫料相交的高度范围预留空腔，留洞能看到下面的垫料。

30 cm 腿的网页零件 ID 为 Y01–Y04，价格独立定义为 `extraTallLegSurcharge`。`scripts/prepare-tall-legs.py` 从源 X01–X04 的 20 cm 网格延长中段，保留两端轮廓与顶部磁座；输出保持水密、总长 300 mm。新增腿是网页预览派生件，未写入现有生产 3MF。

## 仓鼠模拟

当前暂不开放，等待用户提供更精细的模型。`data/features.ts` 的 `hamsterPreview` 默认关闭，同时隐藏入口、面板和相关引导，不创建场景中的仓鼠模拟。已有存档与搭配编号的仓鼠字段保留以兼容以后恢复。

`data/hamsters.ts` 定义品种与花色，`state.hamster` 保存选中的 ID 或 null。提供金丝熊、三线、一线、公婆、中国仓鼠及相应花色。尺寸用于视觉和通路净空判断，不用于个体测量或繁育判断。

程序化 3D 仓鼠包含步行、嗅探、站立张望及可通行洞口的钻入动作。移动路径以真实模型表面及碰撞为约束，楼梯连接楼层，布局改变后重建可行区域。泳池按空盆展示，不表现游泳。仓鼠和垫料属于场景预览，不计入商品清单或价格。

品种参考：[Merck Veterinary Manual](https://www.merckvetmanual.com/multimedia/table/hamster-breeds-commonly-kept-as-pets)。探索、挖掘等动作参考：[RSPCA 仓鼠行为](https://www.rspca.org.uk/adviceandwelfare/pets/rodents/hamsters/behaviour)。垫料厚度选项是本工具的视觉参数，不是饲养建议。

## 保存与验证

新编号为 HM3，目录版本 6，完整保存三平台、颜色、腿长、垫料、仓鼠和配件。本地自动保存当前配置，撤销/重做历史仅在当前页面会话内保留，刷新不恢复历史。旧 HM1/HM2 与本地保存仍可导入；旧第二平台的前/后/左布局会连同子件移到右侧，显示迁移提示，发生无法解决的碰撞时保留原存档。旧索引与 SKU 不复用。楼梯底座、窗框、帽檐与圆球颜色槽只追加，旧数组和本地存档缺失新槽时补默认杏色，历史丝带、星星和实体颜色位置不变。

本轮最终 `npm test` 的 110 项回归全部通过，TypeScript 检查通过。测试覆盖历史编码、联动配色、整体风格、窗框几何不变、管道去重与真实源件、指定价格、三组小屋旋转及真实阻挡、加深垫料自动升腿、垫料外沿与尺寸测量。

维护入口：`catalog.ts` 管商品、独立配色及联动；`assembly.ts` 管几何、状态和清单；`config-code.ts` 管迁移与编码；`color-styles.ts` 管五种整体风格。`App.tsx` 负责共享状态、20 步历史和画面入口；`MobileWorkbench.tsx` 与 `DesktopWorkbench.tsx` 分别实现手机、桌面工作台。`AssemblyScene.tsx` 组合场景，`scene-annotations.ts` 管选择框与尺寸，`bedding-scene.ts`、`hamster-scene.ts`、`scene-finishes.ts` 分别管理垫料、隐藏的仓鼠预览与材质。
