# HamilyMart · 仓鼠造屋所

移动端优先的真实模型磁吸装配与选购网站。React、TypeScript、Three.js、Vite；不依赖数据库或登录。价格均为演示价格。

## 运行

```sh
npm install
npm run dev
```

终端会输出本机地址与局域网地址。手机与电脑在同一 Wi-Fi 时，可使用局域网地址预览。

```sh
npm test
npm run build
npm run preview
```

生产构建输出 `dist/`，可以部署到支持静态网站的服务。模型和缩略图全部随网站托管，没有外部 CDN 依赖。

## 买家功能

- 从 30 × 30 cm 平台与四根 10 cm 脚开始；可选无腿、10 cm 或 20 cm。第二个平台可沿前后左右任一边完整贴合，两个平台同步腿长。
- 点击商品自动安排可用位置与方向，优先更多磁孔匹配；也可拖动调整。至少两对真实磁孔匹配才可安装，保留碰撞和支撑边界检查，无空间时提示“放不下去了”。
- 五个小圆盖可分别点选移除、恢复；选购圣诞泳池自动替换大圆盖。无腿模式不兼容泳池。
- 选中组件拖动移位、切换可行朝向、逐部件八色换色、删除、撤销。礼物盒丝带、蝴蝶结分别换色，默认均为黄色。
- 平台脚、小屋与二层板/楼梯/三边草栏/两根防转支柱、管道与底座、房屋与盖板均按套餐提供。
- 本地自动保存、版本化搭配编号导出/校验/还原、商品编号与配件编号清单、实时人民币合计。

默认配色采用原模型：雪白 `#F1EADB`、松绿 `#174A3A`、圣诞红 `#B8273C`、金色 `#C99B46`；按用户要求，礼物盒蝴蝶结改为金黄色，其余饰边保留。另有鼠尾草、草莓奶、晴空蓝、香芋紫四种选色。选中组件后可一键恢复默认配色。完整目录包括礼物盒小屋、圣诞帽小屋、L型转角屋、方糖小屋、六种管道、圣诞袜花圃、圣诞食盆、圣诞泳池。

## Agent 维护入口

| 需求 | 文件 |
| --- | --- |
| 商品名称、SKU、价格、套餐内容、基础色 | `src/data/catalog.ts` |
| 磁位、支持面、碰撞占位与旋转约束 | `src/data/catalog.ts`、`src/lib/assembly.ts` |
| 搭配编号版本和序列化 | `src/lib/config-code.ts` |
| 页面文案与交互 | `src/App.tsx` |
| 3D、镜头、拖动与预览 | `src/components/AssemblyScene.tsx` |
| 手机/电脑样式 | `src/styles.css` |
| 模型加载索引 | `src/data/model-index.json` |
| 重新导出原模型 | `scripts/prepare-models.py`，详见 `docs/model-sources.md` |

价格使用人民币分整数。磁吸坐标采用毫米、Z 向上，不依赖缩略图或肉眼网格；模型以源世界坐标保留，实例定位按 `origin` 转换。更换模型时必须同步磁位、支撑面和碰撞体，不可只替换外观。

## 搭配编号

`HM2.…校验值` 是包含完整配置的可复制文本，不是数据库中的短编号，包含第二平台方向、孔盖状态、腿长、泳池及所有配件。继续兼容已有 `HM1` 目录 2/3 编号。修改位置、颜色、脚长或组件会更改编号。输入会先检查格式、长度、版本、CRC、SKU/颜色范围，然后验证整套磁吸装配。编号还原不依赖发送者的本地存储。相同搭配按稳定顺序编码；更新商品目录时请遵守 `docs/catalog.md` 的版本要求。

## 约束

接口以 `unified_complete_8x4_v4` 的真实零件为基础。圣诞帽 G03 按用户要求派生为 136 mm 宽：保留纵向 94 mm 孔距，横向孔距由 146 mm 改为 120 mm，兼容一层双孔和二层原有左侧双孔。磁铁孔仍保持原规格。原 V4 文件保留，派生模型和检查结果见模型来源文档。

碰撞使用保守占位体，可能拒绝极贴近的可行组合；并非通用物理模拟器。新版三边围栏会与反向的圣诞帽小屋、花圃相交，因此它们在二层仅允许相对礼物盒小屋的原始方向，仍可跟随整个套餐旋转。圆盖可在画布点选，泳池通过商品选配，房屋顶盖随套餐提供。磁力与卡扣手感仍以实际打印验证为准。

目录版本 4 可读取版本 2/3 的搭配编号与本地存档：旧四件套餐升级时，新拆出的白柱继承旧二层平台选色，左右草栏继承旧草栏选色。目录 2 的反向屋顶小屋自动调整为围栏允许方向，并显示更新提示；新配置仍严格校验朝向。无法恢复的本地数据不会被启动时的空平台覆盖，开始新搭配时会先备份原存档。

圣诞食盆 O01 补充自真实历史目录 `christmas_villa_v30_pool_cover`，使用旧版 8×2 mm 磁铁；其余零件以 V4 为基础，包含上述派生 G03。它与圣诞袜花圃共用二层双孔位置。来源、硬件差异与几何精度记录见 `docs/model-sources.md`。

当前仅提供配置和清单，不包含支付、订单服务器或商品后台。八种基础色和价格待正式确认。模型来源与资源精度记录见 `docs/model-sources.md`。
