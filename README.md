# HamilyMart · 仓鼠造屋所

移动端优先的真实模型磁吸装配与选购网站。React、TypeScript、Three.js、Vite；不依赖数据库或登录。价格均为演示价格。

## 运行

```sh
npm install
npm run dev
```

终端会输出本机地址与局域网地址。手机与电脑在同一 Wi-Fi 时，可使用局域网地址预览。

```sh
npm test
npx tsx scripts/check-hamster-scene.ts
npm run build
npm run preview
```

生产构建输出 `dist/`，可以部署到支持静态网站的服务。模型和缩略图全部随网站托管，没有外部 CDN 依赖。仓鼠冒烟脚本直接加载真实 GLB，验证房间、楼梯、盆内往返和圆洞钻入路线。

## 买家功能

- 最多三块 30×30 cm 平台，一键向右贴边增加；各平台配色、孔盖和泳池独立。
- 手机与桌面使用独立工作台。手机在顶部模型下保留横滑组件区，左右始终保留 16 px 留白，商品名下显示价格，分类固定底部；选中后部位可横滑、颜色自动换行，单一标题栏负责返回。桌面采用网格商品侧栏并支持指针拖动。
- 页头右侧显示价格并打开搭配清单；3D 画面底部横条依次提供增加平台、切换风格、垫料高度、显示尺寸、清空设计。分享和导入编号在清单内进入。
- 选中组件显示 2.5 px 黄色虚线框（线透明度 0.5、面透明度 0.2），物品名称及旋转、移除位于框上方；合法安装位置显示小圆圈。添加商品立即寻找真实磁吸位置，没有自动布局成功提示；放不下时保留明确反馈。
- 共 13 种可选色，黄色统一为明亮暖黄 `#F3B34E`，保留在原黄色的第 4 个色块位置；杏、绿、红及其他可选色不变，黑色、灰色继续开放。桃木、仿木、深棕全部为纯色，不使用木纹；丝带、五角星、楼梯底座、帽子小屋窗框、帽檐与圆球独立换色，三边草丛统一配色，双支柱跟随二层平台；帽屋细节色与主体相同或同为杏白浅色时自动调整，保持可辨识的对比。
- 圣诞礼物的默认黄色也更新为暖黄，另有四种整体风格：暖木小筑使用桃木、仿木、深棕；草莓奶油以杏、粉、红搭配暖黄；晴空棉云仅用白、浅蓝、杏、暖黄、灰，去掉深绿；琉璃花园以琉璃绿、白、柔粉和暖黄搭配。五种风格都让各平台与其所有圆盖同色、二层平台与楼梯底座同色。手动改色仍保留独立槽，不改变组件位置和数量，风格名称只通过短暂提示显示。
- 薄铺 5 cm，厚铺 10/20/30 cm；圆角蓬松木屑在整组平台四周各扩出 5 cm。腿长可选 0/10/20/30 cm；增加垫料高度时，仅将不足高度的现有腿自动升高，长腿和无腿保持，因此仍支持 30 cm 腿配 20 cm 厚铺。无腿平台放在垫料上。选中平台后才能点选小圆盖、预览留洞。
- 真实磁吸放置、拖动、旋转、移除，支持最多 20 步撤销与重做。清空需确认，恢复成一块默认平台，并可撤销/重做。修改自动保存到本机，没有保存按钮；模型可完整旋转查看底部，底视时暂时隐藏垫料与地面。
- 套餐不可拆售，HM3 自包含搭配编号可复制复现，清单包含配件编号和演示价格。没有已搭建总览入口或单件还原配色按钮。

L 型转角屋的顶盖随风格分别搭配：草莓奶油为杏色、晴空棉云为白色、琉璃花园为粉色；圣诞礼物仍为黄色，暖木小筑仍为桃木。风格名称更新不改变保存的 `original` 标识或搭配编号格式。

目录只展示直管道、弯管道、侧开口直管道、顶开口弯管道四种管道；旧重复款仍可导入，不再重复上架。所有管道含对应底座统一 ¥8，L 型转角屋 ¥35，泳池 ¥25。

完整规则、迁移和维护说明见 [目录 7 体验说明](docs/experience-v7.md)。

## Agent 维护入口

仓鼠预览暂不开放，等待替换更精细的模型。`src/data/features.ts` 的 `hamsterPreview` 同时控制入口、帮助文案和场景实例；旧存档中的选择保留，但不会显示或运行仓鼠。

| 需求 | 文件 |
| --- | --- |
| 商品名称、SKU、价格、套餐内容、基础色 | `src/data/catalog.ts` |
| 磁位、支持面、碰撞占位与旋转约束 | `src/data/catalog.ts`、`src/lib/assembly.ts` |
| 搭配编号版本和序列化 | `src/lib/config-code.ts` |
| 共享状态、历史、画面按钮与清单 | `src/App.tsx` |
| 独立移动端交互与样式 | `src/components/MobileWorkbench.tsx`、`src/components/mobile-workbench.css` |
| 独立桌面工作台 | `src/components/DesktopWorkbench.tsx` |
| 整体风格、材质与独立/联动配色 | `src/lib/color-styles.ts`、`src/lib/scene-finishes.ts`、`src/data/catalog.ts` |
| 3D、镜头、拖动与预览 | `src/components/AssemblyScene.tsx` |
| 选择框、尺寸与悬浮工具栏 | `src/lib/scene-annotations.ts`、`src/components/scene-overlays.css` |
| 垫料体积、木屑与整组外沿 | `src/lib/bedding-scene.ts` |
| 共享与桌面样式 | `src/styles.css` |
| 模型加载索引 | `src/data/model-index.json` |
| 重新导出原模型 | `scripts/prepare-models.py`，详见 `docs/model-sources.md` |

价格使用人民币分整数，所有管道共用 `PIPE_SET_PRICE`。`getProductStyleColors` 与 `getBaseStyleColors` 提供商品和平台完整风格色，供预览与新增组件共用。磁吸坐标采用毫米、Z 向上，不依赖缩略图或肉眼网格；模型以源世界坐标保留，实例定位按 `origin` 转换。更换模型时必须同步磁位、支撑面和碰撞体，不可只替换外观。

## 搭配编号与模型

`HM3.…校验值` 使用目录 7，完整保存三平台、垫料、仓鼠、配色和所有组件；兼容旧 HM1/HM2 和目录 6 的 HM3。颜色索引不移动：`butter` 与历史 `yellow` 都显示同一种暖黄，仅 `butter` 在选择器出现；旧编号保留原颜色 ID，仍可直接分享。改价不改变搭配编号，清单使用当前目录价格。旧目录先按旧几何严格验证，再迁移到新接口；非法旧布局不会因新平台变窄而获准。迁移会提示，无法恢复时保留原始存档且不删除组件。颜色索引和商品 SKU 不重用。

现有主体模型来自 `unified_complete_steel_v16`。A02 二层平台外宽为 300 mm，含草栏、帽屋和支柱的套餐可在三块平台上同向贴边摆放；G05 沿用 V14 上端扣搭、底部单磁铁的楼梯。相对 V14，实际需要重打的只有 A02 与 G15 后草栏，其余五件联动零件仅移动装配位置，可复用原实体。完整生产套装含 49 片钢片、39 枚磁铁；SS01 跷跷板保留底部正中心单磁孔，V16 在 3MF 与网页中都将活动板默认倾斜 10°，固定底座和转轴不移动。圣诞帽窗框仅在网页 GLB 中拆为独立颜色体，网格三角形不变；另增加由 20 cm 腿延长中段得到的 30 cm 预览腿 Y01–Y04。新增无顶开口弯管使用真实 LT2NT 管体和 LT2B 底座；网站共 49 组、57 个颜色体，资源版本为 `steel-v16-render1`；网页转换不改写生产 3MF。详见 [模型来源](docs/model-sources.md)。

当前提供搭配模拟和购买清单，没有支付或订单服务器。价格为演示值。保守碰撞与仓鼠路径用于预览，不替代实物配合及饲养验证。
