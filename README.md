# HamilyMart · 仓鼠造屋所

移动端优先的真实模型磁吸装配与选购网站。React、TypeScript、Three.js、Vite；不依赖数据库或登录。价格均为演示价格。

## 运行

```sh
npm install
npm run dev
```

终端会输出本机地址与局域网地址。手机与电脑在同一 Wi-Fi 时，可使用局域网地址预览。

```sh
npm test
npx tsx scripts/check-hamster-scene.ts
npm run build
npm run preview
```

生产构建输出 `dist/`，可以部署到支持静态网站的服务。模型和缩略图全部随网站托管，没有外部 CDN 依赖。仓鼠冒烟脚本直接加载真实 GLB，验证房间、楼梯、盆内往返和圆洞钻入路线。

## 买家功能

- 最多三块 30×30 cm 平台，一键向右贴边增加；各平台配色、孔盖和泳池独立。
- 移动端上方三分之二固定显示模型，下方三分之一为组件/设置。选中组件后在下方面板操作，返回或确认回到列表。
- 原模型杏/绿/黄/红四色，加白、蓝、大理石、琉璃绿、粉色；丝带与五角星独立换色。
- 真实磁吸自动放置、拖动、旋转、删除和撤销。单磁铁食盆/花圃可使用一层的合法接收位；其他配件仍至少匹配两点。
- 薄铺 5 cm，厚铺 10/20/30 cm 木屑预览。有腿厚铺自动同步腿长；无腿平台放在垫料上。选中平台后才能点选小圆盖、预览留洞。
- 品种与花色可选的 3D 仓鼠，根据模型通路探索、嗅探、张望和钻洞。
- 套餐不可拆售，本地保存、HM3 自包含搭配编号、配件编号与演示价格合计。

完整规则、迁移和维护说明见 [目录 6 体验说明](docs/experience-v6.md)。

## Agent 维护入口

| 需求 | 文件 |
| --- | --- |
| 商品名称、SKU、价格、套餐内容、基础色 | `src/data/catalog.ts` |
| 磁位、支持面、碰撞占位与旋转约束 | `src/data/catalog.ts`、`src/lib/assembly.ts` |
| 搭配编号版本和序列化 | `src/lib/config-code.ts` |
| 页面文案与交互 | `src/App.tsx` |
| 3D、镜头、拖动与预览 | `src/components/AssemblyScene.tsx` |
| 手机/电脑样式 | `src/styles.css` |
| 模型加载索引 | `src/data/model-index.json` |
| 重新导出原模型 | `scripts/prepare-models.py`，详见 `docs/model-sources.md` |

价格使用人民币分整数。磁吸坐标采用毫米、Z 向上，不依赖缩略图或肉眼网格；模型以源世界坐标保留，实例定位按 `origin` 转换。更换模型时必须同步磁位、支撑面和碰撞体，不可只替换外观。

## 搭配编号与模型

`HM3.…校验值` 完整保存三平台、垫料、仓鼠、配色和所有组件；兼容旧 HM1/HM2。旧布局迁移会提示，无法恢复的原始存档会保留。颜色索引和商品 SKU 不重用。

现有主体模型来自 `unified_complete_steel_v9`：钢片接收面、内移草栏、162 mm 二层帽屋和单磁铁食盆。另增加由 20 cm 腿延长中段得到的 30 cm 预览腿 Y01–Y04，未修改 V9 生产 3MF。详见 [模型来源](docs/model-sources.md)。

当前提供搭配模拟和购买清单，没有支付或订单服务器。价格为演示值。保守碰撞与仓鼠路径用于预览，不替代实物配合及饲养验证。
